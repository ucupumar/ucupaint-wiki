## Channel in Ucupaint

A channel in Ucupaint represents a pair consisting of an input and an output within the Ucupaint node. 

|![02.channel-overview.01](./source/02.channel-socket-pairs.gif)|
|:--:|

Each channel has at least one input and one output, except for the `Height` channel, by default it doesn't have an output (read [Displacement Setup](#displacement-setup) for more info).

The base color or value of the channel is the default input of the node, as shown in the GIF below.

## Main Channel Types
There are three channel main types in Ucupaint: `RGB`, `Value`, and `Vector`. Color is an example of a `RGB` channel, Metallic, Roughness, and Height are examples of `Value` channels, and Normal is a `Vector` channel.

### Channel Settings
The channel settings for the selected channel can be accessed under the channel list.

Here are the options available in the channel settings:

- **Background/Base Value**: The node input value of the channel, it is also accessible in the `Base Layer` and beside the channel name in the channel list.
- **Use Clamp**: Limit the value output of the channel to 0.0-1.0 range.
- **Space**: Color space of the channel, use `Color Data` for channel that will used for color, and `Non-Color Data` for channel that will be used for non-color purpose.
- **Bake Target**: The bake target that will be used as the data when baking the Ucupaint node.
- **Special Type**: This option will show up in certain channel, this is to set the channel as special channel explained in [Special Channel Types](#special-channel-types) section

## Special Channel Types

There are special channel types in Ucupaint that do more than regular channels. In version 3.0 the special channel types are `Alpha`, `Height`, `Normal` and `Vector Displacement`.

### Alpha channel

<!-- Ucupaint 2.4.0 introduces new dedicated channel for alpha channel, and it pairs to the color channel by default. Demo of the dedicated alpha channel is available in [YouTube video](https://www.youtube.com/watch?v=EEHSA5tfbU0). -->

Alpha channel need to be paired with to color channel to work effectively.  Alpha channel also uses special blending that make sure the final color is rendered correctly.

<!--
|![pic: Alpha channel settings](./source/02.alpha-channel-settings.png)|
|:--:|
|Alpha channel settings | {align=center}
-->

Specific settings which available in alpha channel are:

- **Channel Pair**: Links a color channel with the alpha channel. When the color channel is enabled on a layer, the alpha channel is automatically activated as well.
- **Backface Mode**: Option to hide the backface or frontface of the object.

### Normal channel

Normal channel is a special channel that outputs world space normal of the object surfaces.

Specific settings which available in alpha channel are:

- **Main UV**: UV Map that will be used for calculating tangent which needed for `Overlay` blending mode

### Height channel

<!-- Height channel by default will be used as bump if there's a normal channel and the option `Use Height as Bump` is enabled. -->
Height channel by default will be used as bump if there's a normal channel and the [Displacement Setup](#displacement-setup) isn't enabled yet.

Specific settings which available in height channel are:

- **Normalize Input Output**: This will normalize the height channel output to fit in 0.0-1.0 range. It also also will create midlevel input that can control the midlevel of the height input.
- **Displacement Setup**: Displacement setup is just a status label. If you do the `Quick Displacement Setup`, this will enable the displacement setup, meaning the height output will be accesible and it's automatically connected to displacement node.

## Displacement Setup

By default, `Height` channel in Ucupaint is for the bump effect on the normal channel, but it is can also work with real displacement, you only need to do displacement setup first. For `Vector Displacement` channel, it is designed to work with displacement setup enabled since the channel can work as sculpt layers (**TODO: more info about that is in different page**)

### Quick Displacement Setup

Button to do `Quick Displacement Setup` is available on both `Height` and `Vector Displacement` channel settings. 

|![pic: quick displacement setup options](./source/02.channel-quick-displacement-setup-options.png)|
|:--:|
| Quick Displacement Setup Options | {align=center}

Options that available for `Quick Displacement Setup`:

- **Method**: To set the displacement method of the current active material.
- **Max Polygons**: Will set the subdivision surface or multires modifiers levels based on `Max Polygons` number. The input is in thousand, so 1000 means 1 million polygons.
- **Adaptive (Cycles Only)**: Will enable adaptive subvision that only works on Cycles renderer. This can improve displacement details, but will increase load time when entering render view.
- **Dicing Rate** : Will appear if adaptive is enabled. Dicing rate is the number of pixels on screen that will determine mesh subdivision.

Doing displacement setup will also do these things:

- Add subdivision surface modifier to all objects that shared the material if there's no subdivision surface modifier yet.
- Set the subdivision level to reach `Max Polygons` input. Notice that the input is in **thousands**, so 1000 mean 1 million polygons.
- If the object already use multires modifier, it will set the levels of the multires modifier instead.
- If the model is detected using flat shading, the subdivion modifier will use the `Simple` type, otherwise it will use `Catmull-Clark` type subdivision.
- Set the displacement method of the material to the chosen method option, the default is `Displacement and Bump` so the height or vector displacement channel can actually displace the surface.
- By default, if there's height and normal channel, height channel output is not accessible. Doing displacement setup will make it available.
- Create displacement node if there's height channel exists and connect the output of the height channel to the displacement node.
- Create vector displacement node if there's vector displacement channel exists and connect the output of the vector displacement channel to the vector displacement node.
- The displacement and vector displacement node will connect to the active material output and if there are both of them, `Add Vector` node will be added.
- All the displacement nodes will only be added if they're don't exist yet, so it's safe to do `Quick Displacement Setup` multiple times to set the target polygons

|![02.channel-overview.02](./source/02.channel-displacement-setup-nodes.png)|
|:--:|
| Necessary displacement nodes will be created after doing `Quick Displacement Setup` | {align=center}

### Remove Displacement Setup

To remove the displacement setup, there's a button beside the quick displacement setup that has the `X` icon.

|![pic: remove displacement setup options](./source/02.channel-remove-displacement-setup-options.png)|
|:--:|
| Remove Displacement Setup Options | {align=center}

The action input will gives you three options:

- **Recover Original State**: This will keep or remove the subdivision modifier based on the first time you did the `Quick Displacement Setup`
- **Remove Subdivision Modifier**: Will remove any subdivision modifiers that exists on all objects that shared the active material.
- **Keep Subdivision Modifier**: Will keep subdivision modifiers and there's an option to set subdivision level.

Other than doing action to the subdivion modifiers, remove displacement setup will also these things:

- Set the displacement method of the material to `Bump Only` so there will be no displacement on the surface
- If there's height and normal channel, height output is no longer accessible
